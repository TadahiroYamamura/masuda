## 書くときの決まり

- 現在形だけで書く。「当初は」「〜という理由で」が出てきたら、それはコミットメッセージの内容
- 1ファイル1関心事。他ファイルの範囲は参照1行で済ませる
- コードが正。記述と実装が食い違ったら実装を正とし、ドキュメントを直す
- 行番号は引用しない（すぐずれる）。関数名・ファイル名で指す
